AlphaSAGE 代码教程

从行情数据到 Mega-Alpha：逐行拆解 GFlowNet 因子生成框架

项目简介

AlphaSAGE 是一个基于 GFlowNet 的 alpha 因子自动生成与组合框架。它的输入是 Qlib 行情数据，输出是可交易的 Mega-Alpha 复合因子，中间依次完成表达式采样、结构编码、池筛选、滚动回归四件事。本教程逐行拆解真实源码，覆盖从数据加载到基线对比的完整闭环。

仓库共 42 个文件、约 35 个 Python 模块，入口包括 train_gfn.py（GFlowNet 训练）、train_ppo.py/train_qcm.py（基线）、run_adaptive_combination.py（Mega-Alpha 组合）、combine_AFF.py（AFF 基线）。配套论文见 [arxiv.org/abs/2509.25055](https://arxiv.org/abs/2509.25055)。

章节目录

第 1 章 · data
数据与特征加载
封装 Qlib 行情数据，按股票×天数×特征组织成张量，提供特征枚举与表达式求值接口，是整个仓库的数据源头。
第 2 章 · data
表达式与算子体系
定义 alpha 表达式的算子、特征、时间常数词表与 AST 求值规则，配合 QLibStockDataCalculator 把表达式算成因子值。
第 3 章 · core
GFlowNet 生成框架
基于 Trajectory Balance 的 GFlowNet，通过前向/后向策略估计器和熵正则项，采样多样化 alpha 表达式轨迹。
第 4 章 · core
RGCN 结构编码器
把 RPN token 序列转成关系图，用 RGCNConv 按六类边关系传递消息，再全局平均池化得到表达式结构嵌入。
第 5 章 · core
Alpha 池管理
维护候选 alpha 集合，按 IC 与互相关阈值筛选入池，支持基于嵌入的 KNN 查找与末位淘汰，保存为 pool_*.json。
第 6 章 · core
多维奖励函数
稠密奖励 = IC + λ_ssl·SSL + λ_nov·新颖度，SSL 基于结构嵌入 KNN 一致性，权重由 WeightScheduler 时间退火。
第 7 章 · io
训练主循环
train_gfn.py 的训练主循环：每轮采样轨迹、计算 TB 损失、按 update_freq 累积梯度更新，并定期记录与保存。
第 8 章 · io
Alpha 动态组合
run_adaptive_combination.py 逐日只用历史窗口筛选 alpha，用最小二乘回归当天权重，输出日度预测与 ret_s.npy。
第 9 章 · io
评估指标
在 calculator 与滚动组合脚本中计算 IC、ICIR、RankICIR、收益、夏普与最大回撤，把预测质量转成可比指标。
第 10 章 · io
Baseline 对比
PPO、QCM（分布式 RL）、AFF 三类基线，与 GFlowNet 共享数据与池接口，用于对照验证生成与组合效果。

论文速览

三个关键设计决策，及其代码证据与理由：

用 GFlowNet 替代 RL 采样

证据：src/alpha_gfn/gflownet.py:81

GFlowNet 采样多样性强于 PPO，可避免模式崩塌

RGCN 作用于 AST 而非序列

证据：src/alpha_gfn/modules.py:13

图结构能捕获算子间关系，序列模型会丢失语法结构

稠密多维奖励 IC+SSL+NOV

证据：src/alpha_gfn/env/core.py:140

单一 IC 奖励导致同质化，SSL 与新颖度保证多样性

如何阅读

按章节顺序阅读：第 1-2 章铺数据与表达式基础，第 3-6 章是核心（GFlowNet 损失、RGCN 编码器、Alpha 池、多维奖励），第 7-10 章是应用（训练循环、动态组合、评估指标、基线对比）。每章都含真实代码卡片（带行号与中文注释）、设计权衡 callout、关联公式（KaTeX 渲染）。左侧侧边栏可随时跳转。
