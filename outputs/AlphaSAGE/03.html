第3章：GFlowNet 生成框架

像一个多路探险家，同时派许多路径去采样不同 alpha，而非只走一条最优路。

这个模块做什么

EntropyTBGFlowNet（src/alpha_gfn/gflownet.py）是 AlphaSAGE 的采样引擎。它的输入是 GFlowNet 轨迹（token 序列）与终点奖励，输出是一个标量损失，中间做两件事：算前向/后向对数概率与 TB 分数，再把误差平方反传。它不找「最优路径」，而是学一个与奖励成正比的概率流，让所有高质量表达式都有机会被采样到，从而避免 PPO 的模式崩塌。

它基于 Trajectory Balance（TB）变体，额外加熵正则项鼓励探索。两个核心方法：get_trajectories_scores 算 log 概率与熵，loss 把 TB 误差与熵项收口成标量。

它解决什么问题？

GFlowNet 的目标是学一个前向策略 $P_F$，使得采样一条轨迹 $\tau$ 到达终点 $x$ 的概率，正比于该终点的奖励 $R(x)$：

$$P_F(\tau) \propto R(x), \quad x = \text{终点}(\tau)$$

这和 RL 的区别在于：RL 最大化期望回报，结果是「贪心」的；GFlowNet 最大化的是轨迹级匹配，结果是「多样」的。对 alpha 生成来说，我们想要的不是某一个最强因子，而是一个分布——池里每个高质量因子都被合理采样，从而支撑后续的组合。

Trajectory Balance 用一个巧妙的等式实现这种匹配：对任意完整轨迹 $\tau$，要求前向概率、后向概率、终点奖励三者满足

$$P_F(\tau)\, Z = P_B(\tau \mid x)\, R(x)$$

其中 $Z$ 是个可学习的标量（对数配分函数）。这个等式一旦成立，采样分布就正比于奖励。EntropyTBGFlowNet 在此基础上减去一个熵项，让策略别太确定——进一步抑制模式崩塌。

核心设计思路

实现上有三个要点。第一，前向/后向双策略网络：pf 生成 token，pb 给定状态反向选 token，两者都是 DiscretePolicyEstimator。第二，logZ 可学习：$\log Z$ 作为参数参与梯度更新，省去显式估计配分函数的麻烦。第三，熵正则按温度缩放：logits 除以 entropy_temperature 再算熵，温度越高探索越强。

代码深入

get_trajectories_scores —— log 概率与熵项

这个方法返回四元组 (log_pf, log_pb, scores, entropy_term)。scores 就是 TB 公式里的 $\log(P_F/P_B R)$，熵项则会作为奖励加进损失。注意它对 entropy_coef <= 0 做了短路，不启用熵正则时直接复用父类结果，零开销。

59        elif self.entropy_coef > 0:

61            non_terminal_mask = ~trajectories.is_done

73                entropy = -torch.sum(

第 41-46 行是熵计算的核心。estimator_outputs 是策略网络在每一步、每条轨迹、每个动作上的 logits。除以温度后 softmax，再用 $-\sum p \log p$ 算每步熵。这一步衡量的是「策略在这一步有多犹豫」——熵高说明它对多个动作都不确定，正是探索的信号。

第 49-53 行的掩码不可忽视。GFlowNet 的轨迹是变长的，批处理时会被填充到 max_len。如果直接对填充步算熵再求和，会引入虚假的探索信号。valid_steps_mask 用 when_is_done 把填充步剔除，保证熵项只反映真实决策步。这种「数值卫生」在 GFlowNet 实现里随处可见，是训练稳定的基础。

第 58 行 entropy_sum_per_trajectory * self.entropy_coef 把熵从「度量」转成「奖励」。注意它在 loss 里是被减去的——最大化熵等价于最小化负熵，所以损失里减去熵项均值，就鼓励策略保持不确定。

loss —— TB 损失核心

这是直接对应论文 $L_{TB}$ 公式的一行。看似简单，但它把前面所有的 log 概率、scores、logZ、熵项收口成一个标量。

82        self,
83        env: Env,
84        trajectories: Trajectories,
85        recalculate_all_logprobs: bool = False,
86    ) -> TT[0, float]:

88
89        The trajectory balance loss is described in 2.3 of
90        [Trajectory balance: Improved credit assignment in GFlowNets](https://arxiv.org/abs/2201.13259))
91
92        Raises:
93            ValueError: if the loss is NaN.
94        """
95        del env  # unused  # env 未使用，丢弃避免 lint 报错
96        _, _, scores, entropy_term = self.get_trajectories_scores(  # 拿到 scores 与熵项（log_pf/log_pb 此处不直接用）
97            trajectories, recalculate_all_logprobs=recalculate_all_logprobs
98        )
99        loss = (scores + self.logZ).pow(2).mean() - entropy_term.mean()  # TB 核心：(scores + logZ)² 取均值，再减熵项均值
100        if torch.isnan(loss):  # NaN 保护：数值不稳时置 inf，跳过本次更新
101            # set inf
102            loss = torch.tensor(float('inf'))
103
104        return loss

第 99 行是整章的灵魂：loss = (scores + self.logZ).pow(2).mean() - entropy_term.mean()。scores 已是 $\log(P_F/P_B R)$，加上 $\log Z$ 后应该趋近于 0（因为 $P_F Z = P_B R$）。平方再取均值，就是 TB 的均方误差。减去 entropy_term.mean() 是熵正则——它让损失在策略太确定时变大，从而把策略推向更均匀的动作分布。

第 100-102 行的 NaN 保护是工程必需。GFlowNet 训练初期 logZ 容易跑飞，导致 (scores + logZ) 爆炸成 NaN。一旦检测到，把损失设为 inf，让训练循环（第 7 章）跳过这次更新，避免 NaN 污染优化器状态。这种防御性编程让训练能跑完上百万步而不崩。

设计权衡为什么用 TB 而不是更简单的 DB（Detailed Balance）？TB 只要求整条轨迹匹配，而 DB 要求每一步匹配。TB 的方差更小、实现更简单，但理论方差较大。对 alpha 生成这种轨迹较短（≤20 步）、奖励稀疏的任务，TB 的简洁性收益更大。额外加熵正则是为了补足 TB 在探索上的不足——TB 本身不保证多样性。
小结EntropyTBGFlowNet 用 TB 公式 $(\log(P_F/P_B R) + \log Z)^2$ 学一个正比于奖励的采样分布，并减去熵项鼓励探索。get_trajectories_scores 算 log 概率与熵，loss 收口成标量。NaN 保护让训练稳定。这是 AlphaSAGE 多样性生成的理论根基。

关联公式

TB 损失的完整形式（含熵正则）：

$$L_{TB} = \mathbb{E}_{\tau}\left[\left(\log\frac{P_F(\tau)}{P_B(\tau\mid x)\,R(x)} + \log Z\right)^2\right] - \lambda_H\, \mathbb{E}[H(\pi)]$$

其中熵项 $H(\pi)$ 是轨迹级累计熵：

$$H(\pi) = -\sum_{t} \sum_{a} \pi_t(a)\, \log \pi_t(a)$$

代码里 scores 就是 $\log(P_F/P_B R)$，第 99 行的 (scores + self.logZ).pow(2).mean() 对应第一项，entropy_term.mean() 对应第二项（已乘 $\lambda_H$ 即 entropy_coef）。数学与代码的对应关系一目了然。

小结

GFlowNet 用 TB 公式把「采样分布正比于奖励」变成一个可优化的均方误差，再用熵正则保多样性。理解了 (scores + logZ)² - entropy 这一行，你就理解了 AlphaSAGE 为什么能生成多样化的 alpha。下一章我们看 GFlowNet 用的「大脑」——RGCN 结构编码器，它把表达式 AST 转成图，让策略能感知表达式的语法结构。
