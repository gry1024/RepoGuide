# 第 6 章：多维奖励函数

欢迎来到第 6 章！本章将带你理解 **多维奖励函数**。

## 它解决什么问题？

> **类比**：像三味调料的递减配方，IC 主味之外加 SSL 与新颖度佐料，随训练推进逐渐收浓。

稠密奖励 = IC + λ_ssl·SSL + λ_nov·新颖度，SSL 基于结构嵌入 KNN 一致性，权重由 WeightScheduler 时间退火。

## 明星函数

### `GFNEnvCore.reward`

- **位置**：`src/alpha_gfn/env/core.py:140`
- **为何重要**：合成 IC+SSL+NOV 三维奖励，GFlowNet 信号源

**关键逻辑**：

```python
ic = calc_ic(pred, label)
ssl = self.pool.compute_ssl_reward(emb)
nov = 1 - max_corr
return ic + lam_ssl * ssl + lam_nov * nov
```

### `AlphaPoolGFN.compute_ssl_reward`

- **位置**：`src/alpha_gfn/alpha_pool.py:220`
- **为何重要**：基于 KNN 一致性的 SSL 奖励，结构感知关键

**关键逻辑**：

```python
neighbors = self._find_k_nearest_neighbors(emb)
weights = softmax(-dists / tau)
return exp(-consistency_loss(emb, neighbors, weights))
```

## 关联公式

$$
r = r_{IC} + \lambda_{ssl}(t)\,r_{SSL} + \lambda_{nov}(t)\,r_{NOV}
$$

$$
r_{SSL} = \exp(-L_{consist}),\quad w_i = \text{softmax}(-\|e_q-e_i\|^2/\tau)
$$
