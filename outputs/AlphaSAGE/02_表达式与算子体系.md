## 明星函数

### `QLibStockDataCalculator._calc_alpha`

- **位置**：`src/alphagen_qlib/calculator.py:20`
- **为何重要**：把表达式按日归一化求值为因子张量，连接语法与数值

**关键逻辑**：

```python
alpha = expr.evaluate(data)
return (alpha - alpha.mean()) / (alpha.std() + 1e-8)
```

- **位置**：`src/alphagen_qlib/calculator.py:48`
- **为何重要**：按权重加权融合多 alpha，Mega-Alpha 的雏形

**关键逻辑**：

```python
result = sum(w * a for w, a in zip(weights, alphas))
return result
```
