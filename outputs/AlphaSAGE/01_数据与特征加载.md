# 第 1 章：数据与特征加载

欢迎来到第 1 章！本章将带你理解 **数据与特征加载**。

## 它解决什么问题？

> **类比**：像菜市场的进货清单，把各类股票行情原料按统一规格整理好供下游取用。

封装 Qlib 行情数据，按股票×天数×特征组织成张量，提供特征枚举与表达式求值接口，是整个仓库的数据源头。

## 明星函数

### `StockData._get_data`

- **位置**：`src/alphagen_qlib/stock_data.py:99`
- **为何重要**：从 Qlib 加载特征并转张量，数据流真正起点

**关键逻辑**：

```python
data = qlib_data_loader.load()
features = torch.tensor(data.values)
return features.reshape(n_days, n_stocks, n_features)
```

### `StockData._load_exprs`

- **位置**：`src/alphagen_qlib/stock_data.py:81`
- **为何重要**：通过 QlibDataLoader 求值表达式，连接 Qlib 与上层

**关键逻辑**：

```python
loader = QlibDataLoader(exprs, start, end)
return loader.load()
```
