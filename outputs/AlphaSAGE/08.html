第 8 章：Alpha 动态组合

run_adaptive_combination.py —— 滚动筛选 + OLS 回归生成 Mega-Alpha

欢迎

欢迎来到第 8 章！前面七章讲了如何训练 GFlowNet 以生成与筛选 alpha。但训练只是手段，最终目标是“用这些 alpha 预测未来收益”。下游需要一个“组合器”，把多个 alpha 加权融合成一个最终预测。这就是 Mega-Alpha。

本章会进入 run_adaptive_combination.py，看 remove_linearly_dependent_cols 如何用 SVD/QR 去除共线因子，以及 run 如何逐日滚动筛选 alpha、用 OLS 回归当天权重、输出预测与 ret_s.npy。

它解决什么问题？

类比来说，Mega-Alpha 像每日换菜单的厨师长，只用历史食材做回归，当天配出最稳的 alpha 混合口味。

训练产出的 alpha 池是静态的，但市场是动态的。某个 alpha 可能在 2020 年表现优异，但 2022 年失灵。如果用固定权重组合，会随时间衰退。AlphaSAGE 的解决方案是“逐日滚动筛选 + OLS 回归”：每一天，用过去一段时间的表现筛选优质 alpha，用最小二乘回归计算当天权重，生成预测。这样组合权重会随市场变化动态调整，适应性强。

核心设计思路

Mega-Alpha 的设计思路是滚动窗口筛选 + 共线性处理 + 最小二乘回归。

滚动窗口筛选：每一天，仅使用过去一段窗口（默认从 0 开始的扩张窗口）的 IC 与 ICIR 来筛选 alpha，只留表现优异的。这避免了“一个 alpha 静态预测”的过拟合问题。

共线性处理：如果多个 alpha 彼此线性相关（同质），OLS 回归会出现奇异矩阵、解不稳定。remove_linearly_dependent_cols 用 SVD 检测并去除共线列，保证回归数值稳定。

最小二乘回归：用 torch.linalg.lstsq 求解 $\beta = (X^\top X)^{-1}X^\top y$，得到当天权重，再用当天特征乘以权重得到预测。

代码深入

remove_linearly_dependent_cols：去除共线因子

这个函数用 SVD 检测并去除共线列，保证回归数值稳定。它是 Mega-Alpha 数值稳定的关键。

def remove_linearly_dependent_cols(x, to_pred, tol=1e-10):
    """
    Remove linearly dependent columns (factors) using QR decomposition with pivoting for speed.
    
    Args:
        x: Training factor matrix (n_samples, n_factors)
        to_pred: Prediction factor matrix (n_stocks, n_factors)
        tol: Tolerance for linear independence
    
    Returns:
        x_filtered: Filtered training matrix
        to_pred_filtered: Filtered prediction matrix
        selected_factors: List of selected factor indices
    """
    if x.shape[1] <= 1:
        return x, to_pred, list(range(x.shape[1]))
    
    # Use SVD for more robust rank detection (faster than iterative QR)
    try:
        U, S, Vh = torch.linalg.svd(x, full_matrices=False)
        
        # Find columns corresponding to significant singular values
        rank = torch.sum(S > tol * S[0]).item()  # Relative tolerance
        
        if rank == 0:
            selected_factors = [0]
        else:
            # Use the first 'rank' columns as they correspond to largest singular values
            selected_factors = list(range(min(rank, x.shape[1])))
            
    except:
        # Fallback to QR decomposition if SVD fails
        Q, R = torch.linalg.qr(x, mode='reduced')
        diag_R = torch.diagonal(R, dim1=-2, dim2=-1)
        pivot_mask = torch.abs(diag_R) > tol
        
        if not torch.any(pivot_mask):
            selected_factors = [0]
        else:
            selected_factors = torch.where(pivot_mask)[0].tolist()
            if len(selected_factors) == 0:
                selected_factors = [0]
    
    # Filter matrices
    x_filtered = x[:, selected_factors]
    to_pred_filtered = to_pred[:, selected_factors]
    
    return x_filtered, to_pred_filtered, selected_factors

看这个函数的设计。第 98 行用 SVD 分解矩阵 X，第 101 行用奇异值计算有效秩：$$\text{rank} = \sum_i \mathbb{1}[\sigma_i > \text{tol} \cdot \sigma_0]$$。如果某个奇异值远小于最大奇异值，说明对应的列是其他列的线性组合，应该被去除。

第 102-107 行选取前 rank 列作为保留的因子。为什么选前 rank 列而不是其他列？因为前 rank 列对应最大的奇异值，代表了矩阵主要的方向，保留它们能丢弃最少信息。

第 111-120 行是 fallback：如果 SVD 失败（例如数值不稳），回退到 QR 分解。这个 fallback 设计避免了“个别数据中有异常导致整个流程崩溃”。

这个函数的存在是因为 AlphaSAGE 的 alpha 池内可能存在高度相关的 alpha（如 TsMean($close, 10) 与 TsMean($close, 20)），如果不处理，OLS 回归会出现极稀奇异矩阵，解出来的权重会极不稳定。

第 439 行是核心：调用 torch.linalg.lstsq(x, y).solution 求解 OLS：$$\beta = (X^\top X)^{-1}X^\top y$$。第 441 行用预测特征乘以权重得到预测：$$\hat{y} = x_{pred}\,\beta$$。

第 443-446 行是异常处理：如果回归失败（例如 NaN），用零预测代替，避免流程崩溃。

数据流

数据流：pool_*.json → exprs2tensor 转张量 → 逐日迭代 → 窗口筛选 → 共线处理 → OLS 回归 → 预测 → 评估指标 → ret_s.npy。

具体来说，加载上一章保存的 pool_*.json，逐个表达式被转成因子张量 fct_tensor（形状 (n_days, n_stocks, n_factors)）。从测试期的第一天开始迭代，每一天用过去窗口筛选优质 alpha、回归当天权重、预测。最后调用 get_tensor_metrics 计算 IC、ICIR、收益、夏普、MDD，输出 ret_s.npy供下游回测使用。

关联公式

$$\beta = (X^\top X)^{-1}X^\top y,\quad \hat{y} = x_{pred}\,\beta$$

这是 OLS 回归的标准公式。对应代码 coef = torch.linalg.lstsq(x, y).solution 与 pred = to_pred @ coef。

这个公式使用了最小二乘法，它在 X 列独立时有解。如果 X 列不独立（共线），X^T X 会奇异，解不唯一。正因为如此，才需要 remove_linearly_dependent_cols 预处理。

设计权衡

为什么选择滚动回归而不是固定权重？因为市场随时间变化，静态权重无法适应。滚动回归让权重随过去表现动态调整，适应市场变化。

为什么用 OLS 而不是岭回归？OLS 计算快、解析式清晰。岭回回归需要调超参数，增加复杂性；且在本场景下不一定优于 OLS。AlphaSAGE 用 SVD/QR 处理共线性后，OLS 已经足够稳定。

为什么默认用扩张窗口（window='inf'）？因为早期数据少，滚动窗口会造成统计不稳；扩张窗口利用所有历史数据，统计更稳定。后期数据多了，可以切换到滚动窗口，更关注近期表现。

小结

本章讲解了 Alpha 动态组合：从 SVD/QR 共线性处理到滚动窗口筛选、OLS 回归生成 Mega-Alpha。这是 AlphaSAGE 落地实际预测的关键步骤。
