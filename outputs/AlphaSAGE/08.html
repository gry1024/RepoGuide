第8章：Alpha 动态组合

像每日换菜单的厨师长，只用历史食材做回归，当天配出最稳的 alpha 混合口味。

这个模块做什么

run_adaptive_combination.py 把候选 alpha 池融合成 Mega-Alpha 复合因子。它的输入是训练保存的 pool_*.json 与行情数据，输出是测试集预测张量与指标字典，中间做三件事：SVD/QR 去共线因子、滚动回归算权重、用权重组合因子值做预测。核心约束是只用历史数据算权重，当天只用这些权重组合已知因子值——严格无未来信息。

三个关键函数：remove_linearly_dependent_cols 去共线、run 主入口、get_tensor_metrics 指标汇总。

它解决什么问题？

组合 alpha 的本质是回归：用历史窗口的因子矩阵 $X$ 拟合目标 $y$，得到权重 $\beta$，再用当天因子值 $x_{\text{pred}}$ 算预测 $\hat{y} = x_{\text{pred}} \beta$。但有两个坑：

第一，共线性：池里因子可能高度相关（即使有互相关阈值，多因子组合时仍会近似共线），直接最小二乘会让 $X^\top X$ 接近奇异，权重数值不稳。第二，未来信息泄露：如果用全样本算权重，回测会作弊。必须严格滚动——每天只用过去窗口的数据。

脚本用 SVD/QR 去共线解决第一个坑，用滚动窗口（window 参数）解决第二个坑。use_weights=True 模式则直接用训练时保存的权重，退化为静态组合——用于快速评估。

核心设计思路

设计上有三个要点。第一，SVD 优先、QR 兜底：SVD 更稳健但稍慢，失败时回退 QR。用相对容差 tol * S[0] 判定秩，适应不同量级。第二，严格时间切分：训练/验证/测试三段，训练段算权重，测试段只算指标，绝不交叉。第三，指标与收益分离：get_tensor_metrics 返回指标字典与逐日收益 ret_s，后者存成 .npy 供回测绘图。

代码深入

remove_linearly_dependent_cols —— 去共线因子

这个函数用 SVD 检测矩阵秩，保留前 rank 个独立列。SVD 失败时回退 QR 分解。它保证回归的数值稳定性。

run_adaptive_combination.py第 79-126 行
79def remove_linearly_dependent_cols(x, to_pred, tol=1e-10):  # SVD/QR 去共线因子，保证回归数值稳定
80    """  # 用带主元的 QR 分解检测线性无关列
81    Remove linearly dependent columns (factors) using QR decomposition with pivoting for speed.
82    
83    Args:
84        x: Training factor matrix (n_samples, n_factors)
85        to_pred: Prediction factor matrix (n_stocks, n_factors)
86        tol: Tolerance for linear independence
87    
88    Returns:
89        x_filtered: Filtered training matrix
90        to_pred_filtered: Filtered prediction matrix
91        selected_factors: List of selected factor indices
92    """
93    if x.shape[1] <= 1:  # 单列直接返回，无需去共线
94        return x, to_pred, list(range(x.shape[1]))
95    
96    # Use SVD for more robust rank detection (faster than iterative QR)
97    try:
98        U, S, Vh = torch.linalg.svd(x, full_matrices=False)  # SVD 分解，奇异值反映各方向能量
99        
100        # Find columns corresponding to significant singular values
101        rank = torch.sum(S > tol * S[0]).item()  # Relative tolerance  # 相对容差判定秩：奇异值 > tol × 最大奇异值
102        
103        if rank == 0:
104            selected_factors = [0]  # 秩为 0 时退化保留第 1 列
105        else:
106            # Use the first 'rank' columns as they correspond to largest singular values
107            selected_factors = list(range(min(rank, x.shape[1])))  # 取前 rank 列作为独立因子子集
108            
109    except:  # SVD 失败时回退 QR 分解
110        # Fallback to QR decomposition if SVD fails
111        Q, R = torch.linalg.qr(x, mode='reduced')  # QR 分解（reduced 模式）
112        diag_R = torch.diagonal(R, dim1=-2, dim2=-1)  # R 对角线元素大小反映列独立性
113        pivot_mask = torch.abs(diag_R) > tol  # 对角线绝对值 > tol 视为独立列
114        
115        if not torch.any(pivot_mask):
116            selected_factors = [0]
117        else:
118            selected_factors = torch.where(pivot_mask)[0].tolist()  # 无独立列则退化保留第 1 列
119            if len(selected_factors) == 0:
120                selected_factors = [0]
121    
122    # Filter matrices
123    x_filtered = x[:, selected_factors]  # 按选中列索引过滤训练矩阵
124    to_pred_filtered = to_pred[:, selected_factors]  # 同步过滤预测矩阵，保持列对齐
125    
126    return x_filtered, to_pred_filtered, selected_factors

第 98-101 行的 SVD 秩判定是数值代数的标准操作。奇异值 $S = [s_1, s_2, ...]$ 按降序排列，$s_1$ 是最大值。秩 = 满足 $s_i > \text{tol} \cdot s_1$ 的奇异值个数。用相对容差（乘以 $s_1$）而非绝对容差，能适应不同量级的因子矩阵——这点很重要，因为按日归一化的因子量级接近 1，而原始收益可能很小。

第 109-118 行的 QR 回退是工程稳健性的体现。SVD 在极端情况下（比如全零列）可能抛异常，except 捕获后用 QR 分解兜底。QR 的 R 矩阵对角线元素反映列的「主元贡献」，绝对值大于 tol 的视为独立。这种「主方法 + 兜底」的双层防御，让函数对任何输入都不崩溃——这是生产级代码的标志。

第 123-124 行同步过滤训练矩阵与预测矩阵，保证列对齐。如果只过滤训练矩阵，预测时维度不匹配会直接报错。这种「成对操作」是组合脚本的隐含契约。

get_tensor_metrics —— 指标汇总

把预测张量与目标张量转成全套评估指标。注意 IC 标准差的保护性下限。

243def get_tensor_metrics(x, y, risk_free_rate=0.0):  # 汇总 IC/RankIC/收益/夏普/MDD 的总指标函数
244    # Ensure tensors are 2D (days, stocks)
245    if x.dim() > 2: x = x.squeeze(-1)  # 确保张量是 2D (days, stocks)
246    if y.dim() > 2: y = y.squeeze(-1)
247
248    ic_s = batch_pearsonr(x, y)  # Pearson IC：线性相关性
249    ric_s = chunk_batch_spearmanr(x, y, chunk_size=args.chunk_size)  # Spearman RankIC：单调相关性，分块省内存
250    ret_s = batch_ret(x, y)  # 逐日收益
251
252    ic_s = torch.nan_to_num(ic_s, nan=0.)  # NaN 填 0，防止后续统计出错
253    ric_s = torch.nan_to_num(ric_s, nan=0.)
254    ret_s = torch.nan_to_num(ret_s, nan=0.) / args.label_days  # 收益按标签天数归一化
255    ic_s_mean = ic_s.mean().item()
256    ic_s_std = ic_s.std().item() if ic_s.std().item() > 1e-6 else 1.0  # IC 标准差过小则置 1，防止 ICIR 爆炸
257    ric_s_mean = ric_s.mean().item()
258    ric_s_std = ric_s.std().item() if ric_s.std().item() > 1e-6 else 1.0  # RankIC 标准差同理保护
259    ret_s_mean = (ret_s).mean().item()
260    ret_s_std = (ret_s).std().item() if (ret_s).std().item() > 1e-6 else 1.0
261
262    # Calculate Sharpe Ratio and Maximum Drawdown for ret series
263    ret_sharpe = batch_sharpe_ratio(ret_s, risk_free_rate).item()  # 夏普比率：收益均值/标准差
264    ret_mdd = batch_max_drawdown(ret_s).item()  # 最大回撤：收益曲线峰谷最大跌幅
265
266    result = dict(  # 组装指标字典
267        ic=ic_s_mean,
268        ic_std=ic_s_std,
269        icir=ic_s_mean / ic_s_std,
270        ric=ric_s_mean,
271        ric_std=ric_s_std,
272        ricir=ric_s_mean / ric_s_std,
273        ret=ret_s_mean * len(ret_s) / 3,  # 收益年化口径（× 天数/3）
274        ret_std=ret_s_std,
275        retir=ret_s_mean / ret_s_std,
276        ret_sharpe=ret_sharpe,
277        ret_mdd=ret_mdd,
278    )  # 返回指标字典与逐日收益
279    return result, ret_s

第 256-258 行的保护性下限很关键。ICIR = IC均值/IC标准差，如果标准差极小（比如某些日子 IC 恰好相同），ICIR 会爆炸成天文数字。if std > 1e-6 else 1.0 把下限设为 1，避免这种假象。这种「除法保护」在金融指标计算里随处可见，是数值卫生的基本功。

设计权衡为什么默认 use_weights=True 而非滚动回归？因为滚动回归计算量大（每天一次最小二乘），且在池容量小时容易过拟合。直接用训练权重更稳、更快，适合快速评估。滚动回归适合最终生产预测，能适应市场风格切换。脚本同时支持两种模式，由 --use_weights 开关控制。
小结run_adaptive_combination.py 用 SVD/QR 去共线保证回归稳定，用严格时间切分防止未来信息泄露。use_weights 模式做静态组合，滚动模式做动态组合。get_tensor_metrics 汇总全套指标，ret_s.npy 供回测。这是 Mega-Alpha 从候选池到可交易预测的最后一公里。

关联公式

最小二乘回归与预测：

$$\beta = (X^\top X)^{-1} X^\top y, \quad \hat{y} = x_{\text{pred}}\, \beta$$

对应滚动回归模式（脚本里 else 分支）。use_weights 模式则是$\hat{y} = X w$，$w$ 来自训练保存的权重。最大回撤定义：

$$\text{MDD} = \max_t \left( \max_{\tau \leq t} R_\tau - R_t \right)$$

其中 $R_t$ 是累计收益。对应 batch_max_drawdown（第 264 行）。

小结

Mega-Alpha 的诞生过程：去共线保证稳定，滚动回归适应变化，指标汇总评估质量。生成器产出的候选池在这里变成可交易预测。下一章我们专门看评估指标——IC、ICIR、RankICIR、夏普、回撤，它们是衡量整套系统成败的尺子。
