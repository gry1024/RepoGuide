# 第 7 章：训练主循环

欢迎来到第 7 章！本章将带你理解 **训练主循环**。

## 它解决什么问题？

> **类比**：像乐队指挥，按节拍采样轨迹、调度权重、回传梯度，把生成器一步步推向高产。

train_gfn.py 的训练主循环：每轮采样轨迹、计算 TB 损失、按 update_freq 累积梯度更新，并定期记录与保存。

## 明星函数

### `train`

- **位置**：`train_gfn.py:141`
- **为何重要**：训练入口主循环，串联数据/环境/模型/优化器

**关键逻辑**：

```python
for episode in range(n_episodes):
    traj = gfn.sample_trajectory(env)
    loss = gfn.loss(traj)
    loss.backward()
    optimizer.step()
```

### `WeightScheduler.get_current_weights`

- **位置**：`train_gfn.py:131`
- **为何重要**：SSL/NOV 权重退火调度，论文时间退火核心

**关键逻辑**：

```python
lam_ssl = lam0 * (1 - t/T)
lam_nov = nov0 * (1 - t/T)
return lam_ssl, lam_nov
```

## 关联公式

$$
\lambda(t) = \lambda_0 \cdot \text{scheduler}(t;\,\lambda_0, \lambda_T)
$$
