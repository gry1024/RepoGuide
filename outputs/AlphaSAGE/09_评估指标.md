# 第 9 章：评估指标

欢迎来到第 9 章！本章将带你理解 **评估指标**。

## 它解决什么问题？

> **类比**：像体检报告的多项指标，IC、ICIR、RankICIR、回撤与夏普一起给出 alpha 健康度。

在 calculator 与滚动组合脚本中计算 IC、ICIR、RankICIR、收益、夏普与最大回撤，把预测质量转成可比指标。

## 明星函数

### `QLibStockDataCalculator._calc_ICIR`

- **位置**：`src/alphagen_qlib/calculator.py:29`
- **为何重要**：ICIR = IC/std，衡量 alpha 稳定性的核心

**关键逻辑**：

```python
ic = daily_corr(pred, label)
return ic.mean() / (ic.std() + 1e-8)
```

### `get_tensor_metrics`

- **位置**：`run_adaptive_combination.py:243`
- **为何重要**：汇总 IC/RankIC/收益/夏普/MDD 的总指标函数

**关键逻辑**：

```python
ic = daily_corr(pred, label)
icir = ic.mean() / ic.std()
return {ic, icir, sharpe, mdd, ret}
```

## 关联公式

$$
ICIR = \frac{\bar{IC}}{\sigma_{IC}},\quad RankICIR = \frac{\bar{RIC}}{\sigma_{RIC}}
$$
