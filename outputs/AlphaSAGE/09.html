第9章：评估指标

像体检报告的多项指标，IC、ICIR、RankICIR、回撤与夏普一起给出 alpha 健康度。

欢迎

一个 alpha 好不好，不能只看一两天的 IC。AlphaSAGE 用一套多维评估指标给 alpha 做体检：IC 看预测力，ICIR 看稳定性，RankICIR 看单调性（对极端值稳健），夏普看风险调整收益，最大回撤看尾部风险。这些指标分散在 calculator.py 与 run_adaptive_combination.py 里，共同构成评估体系。

本章梳理这套指标体系，重点拆解 calculator.py 的 IC/ICIR 实现与 run_adaptive_combination.py 的 get_tensor_metrics。你会看清每个指标的数学定义、代码实现与适用场景——下次看到回测报告，你就能判断哪些指标可信、哪些有水分。

它解决什么问题？

评估 alpha 的难点在于「好坏」是多维的。一个 IC=0.05 的因子，如果每天都稳定 0.05（ICIR 高），可能比一个平均 IC=0.08 但剧烈波动的因子更值得交易——因为前者可预测、可加仓，后者随时可能失效。同理，Pearson IC 对线性关系敏感，但因子与收益的关系往往非线性，这时 RankIC（Spearman 秩相关）更稳健。

AlphaSAGE 的指标体系覆盖五个维度：

预测力（IC/RankIC）、稳定性（ICIR/RankICIR）、收益（年化 ret）、风险调整收益（Sharpe）、尾部风险（MDD）。每个维度都有对应的代码实现，且都做了数值保护（除零、NaN），保证对任何输入都返回合理结果。

核心设计思路

设计上有三个要点。第一，Pearson 与 Spearman 并存：前者算线性相关，后者算秩相关，对极端值更稳健。第二，ICIR 用序列统计：不是单点 IC，而是 IC 序列的均值/标准差，衡量跨日稳定性。第三，除法保护：标准差过小时置 1，避免 ICIR 爆炸。这些细节决定了指标的可信度。

代码深入

calculator.py —— IC 与 ICIR 实现

这里实现了 IC、ICIR、RankIC、RankICIR 的核心计算。注意 Pearson 与 Spearman 的分工，以及 ICIR 的序列统计口径。

42        # return batch_pearsonr(value1, value2).mean().item()

44        RIC = aaa.mean().item()  # RankIC 均值

第 23-24 行的 _calc_IC 用 batch_pearsonr 逐日算 Pearson 相关，再取均值得到单标量 IC。这是最经典的 alpha 度量：IC 越高，因子值与未来收益的线性相关性越强。但单点 IC 不够——第 29-33 行的 _calc_ICIR 看的是 IC 序列的「信噪比」。

第 30-33 行先取逐日 IC 序列 aaa，再算均值与标准差的比值。这个口径很重要：ICIR 衡量的是「平均每天 IC 有多稳定」，而不是「某一天 IC 有多高」。一个 ICIR=2 的因子意味着IC 均值是标准差的 2 倍，统计上显著且可持续。

第 35-46 行的 RankIC/RankICIR 用 Spearman 秩相关代替 Pearson。区别在于：Pearson 对原始数值算相关，受极端值影响大；Spearman 先把数值转成排名再算相关，只看「单调关系」强弱。对 alpha 而言，我们关心的是「因子值大的股票收益是否也大」，这是单调性问题，RankIC 比 IC 更贴切。两套指标并存，让评估能同时覆盖线性与非线性关系。

get_tensor_metrics —— 全套指标汇总

这个函数把预测张量与目标张量转成指标字典，覆盖 IC/RankIC/收益/夏普/回撤。注意第 256 行的除法保护——数值卫生的典范。

第 263 行的夏普比率和第 264 行的最大回撤是组合评估的双支柱。夏普看「单位风险的超额收益」，高夏普说明赚得稳；MDD 看「最坏时刻的亏损幅度」，低 MDD 说明扛得住极端行情。一个 alpha 组合如果 IC 高但 MDD 也高，说明它靠几次大赌赢，不可持续——这种组合在实盘里会让人夜不能寐。

第 256 行 if ic_s_std > 1e-6 else 1.0 是容易被忽略却极重要的保护。ICIR = IC均值/IC标准差，当标准差极小时（比如测试集只有几天且 IC 恰好相同），ICIR 会爆炸成天文数字，给出虚假的「极优」信号。把下限设为 1，让这种退化情况下 ICIR 退化为 IC 均值本身，避免误导。第 258 行对 RankIC 标准差做了同样保护。

设计权衡为什么同时报 IC 与 RankIC？因为它们捕捉不同信号。IC 对线性敏感，适合「因子值线性映射到收益」的简单策略；RankIC 对单调敏感，适合「按因子排名分层选股」的策略。实盘里后者更常见，所以 RankICIR 往往比 ICIR 更能反映真实可用性。两套都报，不偏废。
小结评估指标体系覆盖预测力（IC/RankIC）、稳定性（ICIR/RankICIR）、收益（ret）、风险调整（Sharpe）、尾部风险（MDD）。Pearson 与 Spearman 并存，除法保护防爆炸。看回测时五个维度一起看，才能判断 alpha 真实质量。

关联公式

IC 与 ICIR 的定义：

$$\text{ICIR} = \frac{\overline{\text{IC}}}{\sigma_{\text{IC}}}, \quad \text{RankICIR} = \frac{\overline{\text{RIC}}}{\sigma_{\text{RIC}}}$$

对应第 33 行与第 46 行。夏普比率与最大回撤：

$$\text{Sharpe} = \frac{\mathbb{E}[r]}{\sigma_r}, \quad \text{MDD} = \max_t\left(\max_{\tau\leq t} R_\tau - R_t\right)$$

对应第 263-264 行。这五个指标共同构成 alpha 的「体检报告」。

小结

本章梳理了 AlphaSAGE 的评估指标体系。IC/ICIR 管预测力与稳定性，RankIC/RankICIR 对极端值更稳健，Sharpe 与 MDD 衡量收益质量。数值保护（除法下限、NaN 填零）让指标对任何输入都可信。下一章我们看 Baseline 对比——PPO、QCM、AFF 如何与 GFlowNet 同场竞技。
