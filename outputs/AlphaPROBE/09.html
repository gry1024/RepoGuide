第9章：Mega-Alpha 动态组合

像投资组合经理，每天重新评估池中因子的近期表现，选出最优子集做线性回归预测。

欢迎

训练循环产出了一个高质量、多样化的因子池，但单个因子的预测力终究有限。AlphaPROBE 的最终目标是把这些因子融合成一个稳健的「Mega-Alpha」预测。本章拆解 run_adaptive_combination.py 与 AlphaKnowledgeLogger.load_test_res，看它如何每天重新评估池中因子的近期表现，用 OLS 回归 + 共线性去除生成日度预测。这是 AlphaPROBE 从「因子挖掘」走向「可交易信号」的最后一公里。

它解决什么问题？

因子组合的核心难题是「权重怎么定」。静态权重（如等权、IC 加权）无法适应市场风格切换——某因子在过去一年表现优异，下个月可能完全失效。AlphaPROBE 用滚动窗口动态组合解决：每天只用历史窗口内的因子表现数据，重新筛选有效因子并 OLS 回归当天权重，预测下一天收益。这样组合能自动适应因子表现的时变特性。

类比投资组合经理：每天开盘前，他重新审视池中每个因子近期的 IC/ICIR，选出近期仍有效的因子（IC 超阈值），剔除共线性过高的因子（避免重复下注），用历史数据回归出当天最优权重，生成预测。这套流程每天重跑，让组合始终跟随市场。

核心设计思路

设计上有五个关键点。第一，预计算逐日指标：先把池中所有因子在全程的逐日 IC/RankIC预计算成张量，避免每天重复算。第二，滚动窗口筛选：每天用历史窗口的 IC/ICIR筛出有效因子（threshold_ric 与 threshold_ricir）。第三，共线性去除：用 SVD/QR 检测并移除线性相关的因子列，保证回归数值稳定。第四，OLS 回归：torch.linalg.lstsq 解最小二乘，用历史因子值预测未来收益，权重用于当天预测。第五，lookahead 避免：用 shift = label_days + 1 偏移，确保回归窗口不含未来标签信息。

代码深入

remove_linearly_dependent_cols —— 共线性因子去除

用 SVD 检测因子矩阵的秩，移除线性相关的因子列，保证 OLS 回归数值稳定。这是组合阶段的数值保护层。

79def remove_linearly_dependent_cols(x, to_pred, tol=1e-10):  # 移除线性相关的因子列（共线性检测）
80    """
81    Remove linearly dependent columns (factors) using QR decomposition with pivoting for speed.
82    
83    Args:
84        x: Training factor matrix (n_samples, n_factors)
85        to_pred: Prediction factor matrix (n_stocks, n_factors)
86        tol: Tolerance for linear independence
87    
88    Returns:
89        x_filtered: Filtered training matrix
90        to_pred_filtered: Filtered prediction matrix
91        selected_factors: List of selected factor indices
92    """
93    if x.shape[1] <= 1:  # 单因子直接返回
94        return x, to_pred, list(range(x.shape[1]))
95    
96    # Use SVD for more robust rank detection (faster than iterative QR)
97    try:
98        U, S, Vh = torch.linalg.svd(x, full_matrices=False)  # SVD 分解因子矩阵
99        
100        # Find columns corresponding to significant singular values
101        rank = torch.sum(S > tol * S[0]).item()  # Relative tolerance  # 用相对容差判定有效秩
102        
103        if rank == 0:
104            selected_factors = [0]
105        else:
106            # Use the first 'rank' columns as they correspond to largest singular values
107            selected_factors = list(range(min(rank, x.shape[1])))  # 取前 rank 个奇异值对应的因子
108            
109    except:
110        # Fallback to QR decomposition if SVD fails
111        Q, R = torch.linalg.qr(x, mode='reduced')  # QR 分解作 SVD 失败时的兜底
112        diag_R = torch.diagonal(R, dim1=-2, dim2=-1)
113        pivot_mask = torch.abs(diag_R) > tol
114          # 对角元大于 tol 的列是独立因子
115        if not torch.any(pivot_mask):
116            selected_factors = [0]
117        else:
118            selected_factors = torch.where(pivot_mask)[0].tolist()
119            if len(selected_factors) == 0:
120                selected_factors = [0]
121    
122    # Filter matrices
123    x_filtered = x[:, selected_factors]  # 按选中因子筛选训练与预测矩阵
124    to_pred_filtered = to_pred[:, selected_factors]
125    
126    return x_filtered, to_pred_filtered, selected_factors

第 98 行的 SVD 是共线性检测的核心：因子矩阵 X 的奇异值若接近 0，说明某些因子是其他因子的线性组合（如 TsSum($close,5) ≈ 5×TsMean($close,5)）。第 101 行用相对容差 S > tol * S[0] 判定有效秩，秩小于因子数说明有冗余。第 107 行取前 rank 个因子（对应最大奇异值），移除冗余列。这一步是 OLS 回归的数值前提——若不除共线性，lstsq 会因矩阵病态产生极大权重，让预测失效。

数据流

输入：训练循环产出的 pool_*.json（表达式列表）、StockData（全程数据）、target（未来 20 天收益）、超参（threshold_ric、threshold_ricir、n_factors、window、label_days）。预计算：把所有因子在全程求值并归一化成 (T, N, K) 张量，逐日算 IC/RankIC 序列缓存。滚动循环：每天切历史窗口 → 算 ICIR → 双阈值筛因子 → 去除共线性 → OLS 回归 → 生成当天预测。输出：valid 与 test 的全套指标 + ret_s.npy 收益序列。

关联公式

OLS 回归的目标是最小化残差平方和：

$$\hat{\beta} = \arg\min_{\beta} \|X\beta - y\|_2^2 = (X^T X)^{-1} X^T y$$

预测为因子值与权重的线性组合：

$$\hat{r}_{t+1, n} = \sum_{k \in \text{selected}} x_{t, n, k} \cdot \hat{\beta}_k + \hat{\beta}_0$$

其中 $X \in \mathbb{R}^{(T \cdot N) \times K}$ 是历史因子值矩阵，$y$ 是对应未来收益，$\hat{\beta}$ 是 OLS 解（含截距 $\hat{\beta}_0$）。代码第 377 行的 torch.linalg.lstsq 在数值上用 SVD 分解求解，比直接算 (X^T X)^{-1} X^T y 更稳健——这也是前面要先做共线性去除的原因：若 X 接近奇异，SVD 仍会给出解但权重会极大，共线性去除让 X 列满秩，保证解有意义。

设计权衡

为什么用 OLS 而非 Ridge/Lasso？因为 AlphaPROBE 已经在前面做了多重共线性去除（remove_linearly_dependent_cols + remove_linearly_dependent_rows），X 列满秩后 OLS 解稳定，正则化反而会引入偏差。代价是对极端共线性敏感——若 SVD 容差设太松（linear_dep_tol 默认 1e-10），仍可能漏掉冗余因子，此时 OLS 权重会膨胀。源码里也提供了 remove_multicollinearity_vif（VIF 阈值法）作备选，让用户按需切换。这种「先除共线性再 OLS」的两步法，比直接 Ridge 更显式可控。

小结

Mega-Alpha 动态组合用「预计算逐日指标 → 滚动窗口双阈值筛因子 → 共线性去除 → OLS 回归预测」四步法，每天重生成权重以适应因子表现的时变特性。shift = label_days + 1 严格避免 lookahead bias，torch.linalg.lstsq 给出数值稳健的 OLS 解。这套流程让因子池从「静态资产」变成「动态信号」，是 AlphaPROBE 落地为可交易 alpha 的最后一公里。下一章我们看AlphaPROBE 与其他 alpha 挖掘流派的对比。
