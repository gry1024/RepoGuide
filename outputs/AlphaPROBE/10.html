第10章：Baseline 对比

像 A/B 测试，GFlowNet/FQF/IQN/QRDQN/GAN/PPO 是不同流派的「选手」，与 AlphaPROBE 的 LLM+DAG 路线对比。

欢迎

AlphaPROBE 不是凭空出现的，它要在已成熟的 alpha 挖掘流派里证明自己。本章拆解仓库里的六个 baseline 训练脚本——train_gfn.py（GFlowNet）、train_qcm.py（FQF/IQN/QRDQN）、train_AFF.py（GAN）、train_ppo.py（PPO）、train_GP.py（遗传规划）、combine_AFF.py（AlphaFactory 集成），看它们各自的技术路线、与 AlphaPROBE 的关键差异，以及为什么 AlphaPROBE 选择 LLM + DAG 这条新路径。

它解决什么问题？

alpha 挖掘的 baseline 大致分三类。强化学习派：把表达式生成建模成动作序列决策（每步选一个 token），用 PPO/GFlowNet/Q-learning 学策略。优点是端到端可微，缺点是探索空间巨大、训练慢、易陷入局部最优。生成模型派：用 GAN/VAE 学习「好因子」的分布再采样，优点是能批量生成，缺点是模式坍塌与判别器设计困难。演化算法派：用遗传规划（GP）做表达式树的交叉变异，优点是天然适合 DSL，缺点是变异无方向、易早熟。

AlphaPROBE 与它们的核心区别是「用 LLM 替代策略网络/遗传算子」做变异，用 DAG + 贝叶斯检索做有方向探索。本章用代码对比让差异看得见。

核心设计思路

六个 baseline 共享同一个数据接口（StockData）和池机制（AlphaPool），差别只在「如何生成新表达式」：GFlowNet学一个前向策略网络，按轨迹概率采样表达式；FQF/IQN/QRDQN用分布强化学习建模动作价值分布；GAN训练生成器对抗判别器；PPO用策略梯度优化 actor-critic；GP做表达式树交叉变异；AlphaFactory集成多源因子。AlphaPROBE 用 LLM + DAG 在「变异方向性」与「探索记忆」上突破——这是后文要对比的关键。

代码深入

train_gfn.py —— GFlowNet 路线

GFlowNet 把表达式生成建模成 DAG 上的轨迹采样，目标是让前向策略 p_F 与终止奖励 R(x) 成比例。EntropyTBGFlowNet 用 Trajectory Balance 损失 + 熵正则，WeightScheduler 让 SSL/novelty 奖励权重在训练中线性/指数衰减。

GFlowNet 与 AlphaPROBE 的本质区别：GFlowNet 用神经网络学变异策略，需要海量训练样本（默认 1 万 episodes）才能让策略收敛；AlphaPROBE 用 LLM 直接生成，prompt 注入的进化 traces 让 LLM 「一次到位」理解进化方向，20 轮迭代即可。代价是 LLM 调用成本远高于本地神经网络前向，但在研究阶段这种「重思考轻训练」的权衡是合理的。第 84 行的 WeightScheduler 是 GFlowNet 独有的工程细节——SSL/novelty 奖励在探索后期衰减到 0，让模型专注于主奖励（IC），AlphaPROBE 不需要这种调度，因为它的「探索 vs 利用」由贝叶斯检索器的 depth/times 衰减软性管理。

QCM 派与 AlphaPROBE 的区别在「探索机制」：QCM 用 ε-greedy 或熵采样做动作探索，本质是无记忆随机；AlphaPROBE 的贝叶斯检索器综合 ICIR/depth/times/多样性，是有记忆有方向的探索。第 47 行的 AlphaPool 是基类池，没有 AlphaKnowledgePool 的 topic/description/node 扩展字段——QCM 不关心「因子从哪来」，只关心「因子 IC 多少」，这让它无法利用进化信息。

train_AFF.py —— GAN 生成派

GAN 路线训练一个生成器网络，对抗判别器学习「好因子 token 序列」的分布。train_network_generator 是核心，生成器产出 token 序列后转表达式入池。

GAN 与 AlphaPROBE 的最大差异：GAN 是无监督学习因子分布，生成器学到的是「好因子长什么样」的隐式表示；AlphaPROBE 是有引导的变异，LLM 用父表达式 + traces 做「定向修改」。GAN 的常见痛点是模式坍塌——生成器会反复产出几种相似因子，AlphaPROBE 的三策略多样性打分（残差相关/语义/编辑距离）天然避免这一点。代价是 AlphaPROBE 依赖 LLM API，离线批量生成不如 GAN 高效。

PPO 与 AlphaPROBE 的对比最直观：PPO 用神经网络学策略，AlphaPROBE 用 LLM 做策略。PPO 的优势是 on-policy 训练稳定、可微；劣势是策略网络只能学「当前池见过的」模式，泛化能力受限。AlphaPROBE 借助 LLM 的预训练知识，能生成训练池里从未出现过的算子组合（如把 TsCorr 和 TsSkew 嵌套），这是 PPO 的策略网络无法做到的。第 58 行的「significant factors」统计是 PPO 的健康指标，AlphaPROBE 在 alpha_knowledge_trainer.py 里也有类似监控（pool.size 与 best_ic_ret）。

train_GP.py —— 遗传规划

GP 用 utils.gplearn 做表达式树交叉变异，_metric 是适应度函数（IC），用 LRU 缓存避免重复求值。

GP 与 AlphaPROBE 的关系最近——都是「在表达式空间做演化」，但变异机制完全不同。GP 用预定义的交叉/变异算子（如子树交换、节点替换），是无方向随机；AlphaPROBE 用 LLM 做语义级变异（如「把 TsMean 换成 TsSkew 以捕捉分布偏态」），是有语义方向。GP 的优势是无需 LLM、可大规模并行；劣势是变异质量低、易早熟。第 27 行的 cache 是 GP 的工程优化，AlphaPROBE 也有类似机制——expression_knowledge_graph.py:153 的查重返回已有节点，避免重复建图。

AlphaFactory 集成 —— combine_AFF.py

combine_AFF.py 集成 AlphaFactory 的多源因子，与 AlphaPROBE 自产因子融合。它体现了 AlphaPROBE 的开放性——可以作为因子源接入更大的 alpha 工厂。

这种集成能力是 AlphaPROBE 区别于其他 baseline 的工程优势：GFlowNet/PPO/GP 都是封闭管线，难以注入外部因子；AlphaPROBE 的池与图谱以表达式字符串为媒介，天然支持与外部因子源互操作。组合阶段（第 9 章）的 load_alpha_pool_by_path 接受 JSON/CSV 格式的外部因子列表，让 AlphaPROBE 既能独立运行，也能作为 alpha 工厂的一环。

数据流

共同输入：StockData（训练/验证/测试）、target（未来 20 天收益）、AlphaPool 池机制。差异点：GFlowNet/QCM/PPO 把池包装成 RL 环境用 AlphaEnv；GAN 用 Collector 收集训练数据；GP 直接调 SymbolicRegressor；AlphaPROBE 用 AlphaKnowledgeTrainer 串接 LLM 与图谱。共同输出：pool_*.json 表达式列表，供第 9 章 Mega-Alpha 组合使用。

关联公式

GFlowNet 的 Trajectory Balance 目标是让前向策略与奖励成比例：

$$\mathcal{L}_{\text{TB}} = \left(\log Z + \sum_{s \to s'} \log p_F(s'|s) - \log R(x) - \sum_{s \to s'} \log p_B(s|s')\right)^2$$

PPO 的 clipped surrogate 目标：

$$\mathcal{L}_{\text{PPO}} = \mathbb{E}\left[\min\left(r_t(\theta) \hat{A}_t,\, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) \hat{A}_t\right)\right]$$

对比 AlphaPROBE 的「目标」：无显式损失函数，它通过 LLM prompt + 贝叶斯检索隐式优化「因子池的 ICIR × 多样性」。这种「无梯度优化」让 AlphaPROBE 不必关心反向传播，但也失去了理论收敛性保证——这是用 LLM 替代策略网络的根本权衡。

设计权衡

为什么 AlphaPROBE 选择 LLM 而非强化学习？关键在「探索效率」。RL 的探索靠 ε-greedy 或熵正则，本质是随机扰动；LLM 的探索是语义级变异——它能理解「这个因子在捕捉动量，把它换成波动率版本试试」这种高层抽象。代价是单次变异成本高（LLM API 调用），且依赖模型质量。但 AlphaPROBE 的设计（贝叶斯检索 + DAG 记忆）让每次 LLM 调用都「物有所值」——选最值得进化的因子、用 traces 引导变异方向、用三策略多样性防重复，把 LLM 的每次调用都榨干价值。这种「少而精」的思路，与 GFlowNet 的「多而随机」形成鲜明对比。

小结

六个 baseline 共享数据与池机制，差异在变异机制：GFlowNet 学策略网络，QCM 用分布 RL，GAN 训生成器，PPO 用策略梯度，GP 做树交叉。AlphaPROBE 用 LLM + DAG 在「变异方向性」与「探索记忆」上突破，代价是 API 调用成本。横向对比表清晰展示了这种「重思考轻训练」路线的结构性优势。至此，从数据层到核心层再到应用层与 baseline 对比，AlphaPROBE 的全貌已完整呈现。
