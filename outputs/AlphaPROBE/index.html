AlphaPROBE 深度代码教程

AlphaPROBE：基于 DAG 偏置进化的 alpha 挖掘

Alpha Mining Via Principled Retrieval and On-graph Biased Evolution —— 用贝叶斯检索器与 DAG 感知 LLM 生成器，把 alpha 挖掘建模为 DAG 上的有方向进化。

项目简介

AlphaPROBE（Alpha Mining Via Principled Retrieval and On-graph Biased Evolution）由两大核心组件构成：贝叶斯因子检索器（Bayesian Factor Retriever）综合 ICIR 质量分、depth/times 衰减与三策略多样性，选出 top_k 个最值得进化的因子；DAG 感知因子生成器（DAG-aware Factor Generator）用 LLM 在父因子的进化 traces 引导下生成 N 个语义不同的变体。两者闭环运行，最终产出的因子池用滚动 OLS 组合成 Mega-Alpha 预测。

本教程逐行拆解 AlphaPROBE 的真实代码，按「数据层 → 核心层 → 应用层」三层架构组织 10 章内容，每章包含代码卡片（带行号与中文注释）、数据流分析、关联公式与设计权衡。

论文速览

贝叶斯因子检索器：综合 ICIR 质量分（经 sigmoid 归一化）、depth/times 双衰减（鼓励浅层新因子、避免反复压榨老因子）、三策略多样性（残差相关 / 语义相似度 / 编辑距离），用乘法打分综合三维度，再用 leaf/non_leaf 分组各取 top_k/2，保证探索与利用平衡。

DAG 感知因子生成器：知识图谱记录每个表达式的父节点、depth（变异代数）、times（被选中次数）。path_to_root 追溯一条进化血脉，拼成 traces 喂给 LLM；LLM 在 topic 约束下生成 N 个语义不同的变体，用 12 条校验规则约束输出格式，JSON 解析兜底保证鲁棒性。

闭环与组合：检索→生成→验证→入池→日志五步闭环，双路径入池判定兼顾质量与多样性。最终因子池用滚动窗口 OLS 回归生成 Mega-Alpha 预测，shift = label_days + 1 严格避免 lookahead bias。
