第3章：IC/ICIR 因子评估

像考试的评分员，IC 衡量因子方向是否正确，ICIR 衡量这个方向是否稳定。

本章概览

IC/ICIR 是 AlphaPROBE 衡量因子好坏的两把尺子：IC 衡量因子值与未来收益的线性相关性，ICIR 在 IC 基础上除以标准差，衡量这种相关性的稳定性。本章拆解 src/alphagen_qlib/calculator.py 与 src/alphagen/utils/correlation.py。输入：因子值张量（expr.evaluate(data) 得到的 (T, N)）与 target 张量。中间：按日归一化零均值单位方差，batch_pearsonr 算逐日 Pearson IC 序列，calculator 聚合成 IC/ICIR 标量。输出：IC、ICIR、RankIC、RankICIR 标量，以及与池内因子的互相关列表。

为什么 ICIR 比 IC 更重要？因为 AlphaPROBE 追求「长期稳健」的因子，而非「某段时间爆表」的因子。IC 高但 ICIR 低意味着因子在某些时段极准、在另一些时段反向，这种因子进组合后会放大波动。train_new_work.py:107 甚至单独定义了 icir_decay_threshold，允许 ICIR 略低于父因子但 MutIC 显著降低的表达式入池，可见 ICIR 的中心地位。

核心设计思路

设计上有三个关键点。第一，按日批量向量化：IC 是逐日算的（每天一个横截面相关系数），batch_pearsonr 一次性算出全部天的 IC 序列，避免 Python 循环。第二，NaN 安全：停牌股票会产生 NaN，_mask_either_nan 用掩码把 NaN 统一替换并记录有效股票数 n，保证均值/方差只在有效股票上计算。第三，Pearson 与 Spearman 互补：Pearson IC 对线性关系敏感，Spearman RankIC 对单调关系更稳健，两者都算出来供组合阶段（第 9 章）做因子筛选。

代码深入

batch_pearsonr —— 逐日横截面相关系数

这是 IC 计算的原子操作。它先 mask 掉任一为 NaN 的位置，再按公式算协方差除以标准差。返回长度为 n_days 的张量，每个元素是一天的横截面 Pearson IC。

correlation.py第 7-36 行
7def _mask_either_nan(x: Tensor, y: Tensor, fill_with: float = torch.nan):  # 把任一为 NaN 的位置统一替换，并记录每天有效股票数 n
8    x = x.clone()                       # [days, stocks]
9    y = y.clone()                       # [days, stocks]
10    nan_mask = x.isnan() | y.isnan()  # nan_mask 标记需要剔除的 (day, stock)
11    x[nan_mask] = fill_with
12    y[nan_mask] = fill_with
13    n = (~nan_mask).sum(dim=1)  # n 是每天有效股票数，用于均值/方差归一
14    return x, y, n, nan_mask

17def _rank_data(x: Tensor, nan_mask: Tensor) -> Tensor:
18    rank = x.argsort().argsort().float()          # [d, s]
19    eq = x[:, None] == x[:, :, None]                # [d, s, s]
20    eq = eq / eq.sum(dim=2, keepdim=True)           # [d, s, s]
21    rank = (eq @ rank[:, :, None]).squeeze(dim=2)
22    rank[nan_mask] = 0
23    return rank                                     # [d, s]

26def _batch_pearsonr_given_mask(  # 核心：按日批量算 Pearson 相关
27    x: Tensor, y: Tensor,
28    n: Tensor, mask: Tensor
29) -> Tensor:
30    x_mean, x_std = masked_mean_std(x, n, mask)  # masked_mean_std 只在有效位置算均值与标准差
31    y_mean, y_std = masked_mean_std(y, n, mask)
32    cov = (x * y).sum(dim=1) / n - x_mean * y_mean  # 协方差 = E[xy] - E[x]E[y]
33    stdmul = x_std * y_std
34    stdmul[(x_std < 1e-3) | (y_std < 1e-3)] = 1  # 标准差过小则置 1，避免除零
35    corrs = cov / stdmul
36    return corrs

79def batch_spearmanr(x: Tensor, y: Tensor) -> Tensor:  # Spearman = 先 rank 再 Pearson
80    x, y, n, nan_mask = _mask_either_nan(x, y)  # mask NaN
81    rx = _rank_data(x, nan_mask)  # 对 x 按日排名
82    ry = _rank_data(y, nan_mask)  # 对 y 按日排名
83    return _batch_pearsonr_given_mask(rx, ry, n, nan_mask)
84
85
86def batch_pearsonr(x: Tensor, y: Tensor) -> Tensor:  # Pearson：mask 后用 0 填充再算
87    res =  _batch_pearsonr_given_mask(*_mask_either_nan(x, y, fill_with=0.))
88    # fillna
89    res[res.isnan()] = 0  # 剩余 NaN（如全零日）置 0
90    return res

第 32 行的协方差公式 cov = (x*y).sum(dim=1)/n - x_mean*y_mean 是 IC 的数学核心。它把每天的横截面相关系数向量化算出，n_days 天只需一次张量运算。第 34 行的 stdmul[(x_std<1e-3)|(y_std<1e-3)] = 1 是数值保护：当某天所有股票因子值相同（标准差≈0）时，相关系数无定义，这里把分母置 1 让结果趋向 0，再由第 89 行的 NaN 兜底置 0。Spearman RankIC（第 79-83 行）则是先按日排名再做同样的 Pearson——排名用 argsort().argsort() 实现，并对并列值做平均排名处理。

第 29-33 行的 _calc_ICIR 把 batch_pearsonr 返回的逐日 IC 序列取均值得 IC，再除以标准差得 ICIR。注意第 32 行直接用 .item() 转成 Python float，没有加 epsilon 保护——这是因为上游 batch_pearsonr 已经把全零日的 NaN 置 0，标准差只在真实波动上算。第 18 行的 target_value 在构造期就归一化缓存好，避免每次评估都重算 target。

AlphaPool._calc_ics_and_icir —— 同时算 IC、ICIR 与互相关

AlphaPROBE 的入池判定不仅看单因子 IC/ICIR，还要看它与池内已有因子的互相关（Mutual IC），防止重复因子。这个方法一次性算出三者。

第 233-237 行的循环是新因子与池内每个已有因子算互相关。这个互相关列表会在第 8 章的 try_new_expr 里被用来判断「新因子是否与池内某因子重复」（np.max(ic_mut) <= self.ic_mut_threshold）。它也是第 5 章贝叶斯检索器计算「多样性分」的输入——mutual_ics 矩阵在 search 里被用作 corr_matrix。

数据流

输入：因子值张量（expr.evaluate(data) 得到的 (T, N)）与 target 张量（Ref(close,-20)/close-1 归一化后）。内部：归一化按日零均值单位方差，batch_pearsonr/batch_spearmanr 算逐日相关序列，calculator 聚合成 IC/ICIR 标量。输出：IC、ICIR、RankIC、RankICIR 标量，以及与池内因子的互相关列表。这些值会写入 AlphaKnowledgePool.icir 与 mutual_ics，供检索与入池使用。

关联公式

Pearson IC 是逐日横截面相关系数的均值：

$$\text{IC} = \frac{1}{T}\sum_{t=1}^{T} \rho_t(v, r),\quad \rho_t = \frac{\text{Cov}_t(v, r)}{\sigma_t(v)\sigma_t(r)}$$
$$\text{ICIR} = \frac{\overline{\rho_t}}{\text{std}(\rho_t)} = \frac{\text{IC}}{\sigma_{\text{IC}}}$$

其中 $v$ 是因子值，$r$ 是未来收益，$\rho_t$ 是第 $t$ 天的横截面相关。代码里的 ic_s_mean / ic_s_std（calculator 第 252 行）正对应 ICIR 公式。

设计权衡

为什么 ICIR 比 IC 更重要？因为 AlphaPROBE 追求的是「长期稳健」的因子，而非「某段时间爆表」的因子。IC 高但 ICIR 低意味着因子在某些时段极准、在另一些时段反向，这种因子进组合后会放大波动。因此检索器用 ICIR 而非 IC 作质量分（第 5 章 icir_logit），入池判定也允许 ICIR 略低但 MutIC 显著降低的因子通过（icir_decay_threshold）。

小结

IC/ICIR 评估用「按日批量向量化 + NaN 安全 + Pearson/Spearman 互补」三件套，把因子值与未来收益的相关性收敛成可比的标量。batch_pearsonr 是原子操作，calculator 聚合成 IC/ICIR，AlphaPool 同时算出互相关防止重复。这些指标是第 5 章贝叶斯检索器的质量分基础。
